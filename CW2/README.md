# CoroutineTask — Android Studio

Учебный проект на Kotlin: последовательные и параллельные корутины, отмена, Overlay и ProgressBar.

## Как открыть
1. Распакуй архив.
2. В Android Studio выбери **File → Open** и укажи папку `CoroutineTask`.
3. Дождись Gradle Sync.
4. Запусти приложение на эмуляторе или Android-устройстве.

Требуется Android Studio с JDK 17 и Android SDK 35.

## Как проверить
- Введи `3` и нажми «Запустить последовательно»: задачи выполняются одна за другой, каждая около 5 секунд.
- Введи `3` и нажми «Запустить параллельно»: все три задачи стартуют одновременно и завершаются примерно через 5 секунд.
- Во время работы Overlay блокирует остальной экран; кнопка «Отменить» остаётся доступной.
- Прогресс отображается по шкале 0–10. Для нескольких задач показывается средний прогресс.

## Структура
- `MainActivity.kt` — экран, запуск, отмена и Overlay.
- `Repository.kt` — `doHardWork()` с `delay(500)` десять раз (в сумме 5 секунд).
- `activity_main.xml` — разметка экрана.
